### Cloud Infrastructure Components

**1. Compute Resources**  
**Purpose:** Supplies the CPU and RAM needed to run applications and processes.  
**Importance:** Compute resources serve as the main processing power of digital services and allow systems to scale without requiring physical hardware upgrades.  
**Relation to KillerCoda:** This is represented by the **1 CPU core and 1.9 GiB of RAM** allocated to our Linux terminal environment.

**2. Storage Resources**  
**Purpose:** Provides space for storing system files, applications, and other data.  
**Importance:** Storage allows data to be maintained and accessed when needed while supporting scalability and data management.  
**Relation to KillerCoda:** This is represented by the **virtual storage drives** used to contain the Ubuntu operating system and its files.

**3. Networking Resources**  
**Purpose:** Enables communication between virtual machines, servers, and external networks.  
**Importance:** Networking provides connectivity while also supporting routing and security between different systems.  
**Relation to KillerCoda:** This is represented by the **172.30.1.2 IP address** and the network interfaces that allow the browser-based terminal to communicate.

**4. Operating System (OS)**  
**Purpose:** Manages system resources and provides a platform for running applications and commands.  
**Importance:** The operating system serves as the main software layer between the hardware and applications, making the system easier to manage.  
**Relation to KillerCoda:** KillerCoda uses **Ubuntu Linux**, which provides the command-line environment and tools used to manage and examine the system.
