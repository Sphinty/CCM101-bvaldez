## Tools and Assistance

* **AWS:** Provides **AWS Trusted Advisor** to help identify ways to improve resource usage, security, performance, and cost. **AWS CloudFormation** can also be used to automate infrastructure deployment through infrastructure-as-code templates.
* **Microsoft Azure:** Provides **Azure Advisor** for recommendations related to cost, security, reliability, and performance. **Azure Resource Manager (ARM)** helps organize and manage the deployment of Azure resources.
* **Google Cloud Platform:** Uses **Active Assist** to provide recommendations and insights for improving cloud environments. **Google Cloud Deployment Manager** can be used to automate the deployment and management of cloud resources.
* **AI Assistance:** **Google Gemini** was used to assist with paraphrasing, organizing information, and improving the clarity of the technical explanations.

## Guide Questions

### 1. Which provider offers the broadest range of services?

**AWS** is generally considered to have one of the most extensive selections of cloud services. Its large service portfolio covers areas such as computing, storage, databases, networking, security, analytics, and artificial intelligence.

### 2. Which platform is recommended for Microsoft products?

**Microsoft Azure** is a strong choice for organizations that mainly use Microsoft technologies. Its integration with products such as Windows Server, Microsoft 365, and Microsoft Entra ID makes it convenient for managing existing Microsoft-based environments.

### 3. Which platform is recognized for AI, ML, and Kubernetes?

**Google Cloud Platform (GCP)** is widely recognized for its capabilities in artificial intelligence, machine learning, and Kubernetes. Its services include **Vertex AI** for AI and ML workloads and **Google Kubernetes Engine (GKE)** for deploying and managing Kubernetes applications.

### 4. What similarities did you observe?

All three cloud providers offer the same fundamental categories of cloud infrastructure, including **compute, storage, networking, and identity management**. They also provide scalable resources and flexible pricing models that allow organizations to use cloud services based on their requirements.

## Conclusion

Choosing a cloud provider depends on the organization's existing technology, workload requirements, and business goals. **AWS** is a strong option for organizations that need a wide variety of services, **Azure** is well suited to businesses that rely heavily on Microsoft technologies, while **GCP** is particularly strong in AI, machine learning, data processing, and Kubernetes.
