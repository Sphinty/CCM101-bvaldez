# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think **compute** is the most important cloud infrastructure component because it provides the processing power needed to run applications, services, and workloads. Without compute resources, other components such as storage and networking would have limited purpose. Compute allows the cloud environment to actually perform tasks and provide services to users.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable, flexible, and widely used operating system for cloud servers. During the laboratory, I used Linux commands to check the operating system version, CPU information, memory, storage, hostname, and IP address. These tools make it easier for cloud engineers to monitor and manage infrastructure.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand what needs to be deployed and why. It provides a clear record of the infrastructure design, resources, commands, and decisions. Good documentation also makes troubleshooting easier and helps other team members understand and maintain the environment.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux environment using commands such as `lsb_release`, `uname`, `lscpu`, `free`, `df`, and `hostname`. I also learned more about compute, storage, networking, and identity services and how they work together in cloud infrastructure. Additionally, I improved my Markdown documentation skills.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has improved by adding organized technical documentation and evidence of my laboratory work. It now demonstrates my understanding of Linux and basic cloud infrastructure concepts. This mission also helped me practice presenting technical information in a clear and professional way, making the portfolio more useful for showing my progress and skills.
