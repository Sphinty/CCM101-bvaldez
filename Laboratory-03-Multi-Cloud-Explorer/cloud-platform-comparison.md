## Reflection Questions

1. **Which cloud provider offers the broadest range of services?**
   AWS is generally regarded as offering the broadest and most mature range
   of services, since it has the longest track record and largest catalog
   (200+ services) covering nearly every use case.

2. **Which provider best integrates with Microsoft technologies?**
   Azure best integrates with Microsoft technologies because it is built by
   Microsoft and works natively with Windows Server, Active Directory, and
   Microsoft 365.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   GCP is generally considered strongest here — it created Kubernetes and
   offers GKE as the most mature managed Kubernetes offering, and its Vertex
   AI platform is highly regarded for machine learning workloads.
