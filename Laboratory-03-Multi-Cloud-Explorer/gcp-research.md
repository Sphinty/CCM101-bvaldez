# Google Cloud Platform (GCP) Research

## Brief Overview
GCP is Google's cloud platform, launched in 2008. It leverages the same
infrastructure Google uses for its own products (Search, YouTube, Gmail) and
is known for strengths in data analytics, AI/ML, and Kubernetes.

## Global Infrastructure
GCP infrastructure is organized into **Regions** and **Zones**, connected by
Google's private global network/fiber backbone.

## Cloud Management Console
The **Google Cloud Console** is the web-based management interface. GCP also
offers the `gcloud` CLI and Cloud Shell for direct browser-based terminal
access.

## Four Core Services
1. **Compute Engine** – virtual machine instances.
2. **Cloud Storage** – object storage.
3. **Cloud SQL** – managed relational database.
4. **Identity and Access Management (IAM)** – access control.

## Three Advantages
1. Industry-leading AI/ML tools (Vertex AI, TensorFlow origin).
2. Google Kubernetes Engine (GKE) — GCP created Kubernetes and offers the
   most mature managed Kubernetes service.
3. High-performance global network and strong data analytics tools
   (BigQuery).

## Typical Enterprise Use Cases
- Big data analytics and machine learning pipelines
- Containerized/microservices architectures using Kubernetes
- Real-time data processing
- Startups building AI-driven products
