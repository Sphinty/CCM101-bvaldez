# AWS (Amazon Web Services) Research

## Brief Overview
AWS is the cloud computing platform offered by Amazon, launched in 2006. It is
widely considered the market leader in public cloud, offering the largest and
most mature catalog of cloud services (compute, storage, databases, AI/ML,
networking, IoT, and more).

## Global Infrastructure
AWS infrastructure is organized into **Regions** (geographic areas) and
**Availability Zones** (isolated data centers within a region). As of 2025,
AWS operates dozens of regions worldwide and hundreds of edge locations for
its CDN (CloudFront).

## Cloud Management Console
The **AWS Management Console** is a web-based interface for managing all AWS
services. AWS also offers the AWS CLI and SDKs for programmatic access.

## Four Core Services
1. **Amazon EC2** – Elastic Compute Cloud, resizable virtual machines.
2. **Amazon S3** – Simple Storage Service, object storage.
3. **Amazon RDS** – managed relational database service.
4. **AWS IAM** – Identity and Access Management for controlling access.

## Three Advantages
1. Largest global infrastructure footprint and broadest service catalog.
2. Mature ecosystem with strong third-party/partner support.
3. Flexible pricing (pay-as-you-go, reserved, spot instances).

## Typical Enterprise Use Cases
- Hosting scalable web applications and APIs
- Big data analytics and data lakes
- Disaster recovery and backup
- Media storage and content delivery
