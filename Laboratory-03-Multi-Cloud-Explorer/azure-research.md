# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud platform, launched in 2010. It is known
for deep integration with Microsoft's enterprise software ecosystem
(Windows Server, Active Directory, Microsoft 365, .NET).

## Global Infrastructure
Azure infrastructure is organized into **Regions** and **Availability Zones**,
similar to AWS, with a strong presence in government and enterprise-focused
regions.

## Cloud Management Console
The **Azure Portal** is the primary web-based console. Azure also provides
Azure CLI, PowerShell modules, and ARM/Bicep templates for infrastructure as
code.

## Four Core Services
1. **Azure Virtual Machines** – compute service for VMs.
2. **Azure Blob Storage** – object storage service.
3. **Azure SQL Database** – managed relational database.
4. **Microsoft Entra ID** (formerly Azure Active Directory) – identity and
   access management.

## Three Advantages
1. Seamless integration with Microsoft products (Windows Server, Office 365,
   Active Directory).
2. Strong hybrid cloud tools (Azure Arc, Azure Stack).
3. Favorable licensing for existing Microsoft enterprise customers.

## Typical Enterprise Use Cases
- Hybrid cloud deployments for organizations already using Microsoft tools
- Enterprise identity and access management
- Business application hosting (SAP, .NET apps)
- Government and regulated-industry workloads
